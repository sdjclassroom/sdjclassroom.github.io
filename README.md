---

## 🕹️ About
**SDJClassroom** is a collection of **retro-style web games**, hosted on GitHub Pages.  
The site is designed to be: 
- **Accessible on school networks**, including those filtered by Linewize (By using educational keywords)
- **Unblocked** by default for students who want a quick gaming break during free time

All games are packaged to run directly in the browser with **no downloads or plugins required**.

---

## 🎯 Features
- ✅ Retro-inspired browser games  
- ✅ Fully static site, runs on GitHub Pages  
- ✅ Optimized for **classroom accessibility**  
- ✅ Works on desktop and Chromebook  
- ✅ Simple to extend with new games  

---

## How to Host
- Serve the site locally by running a simple static server, for example:
```bash
python3 -m http.server 8000
```
Open your browser and go to http://localhost:8000
 to view the site.
